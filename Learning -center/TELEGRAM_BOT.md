# 🤖 Telegram-бот и Mini App IT Academy Uzbekistan (@ragm_bot)

Полноценная экосистема учебного IT-центра в Telegram:
1. **Telegram Mini App (`webapp.html`)** — точная мобильная копия всей платформы IT Academy, открывающаяся внутри Telegram по кнопке.
2. **Интерактивный бот (@ragm_bot)** — с поддержкой RAG ИИ-консультанта, базы знаний, каталога курсов, квиза профориентации, калькулятора рассрочки и сквозного сбора заявок с сайта, бота и Mini App.

---

## 📱 Telegram Mini App (Web App)

При нажатии на кнопку **«🚀 Открыть Mini App в Telegram 📱»** или на кнопку меню в левом нижнем углу чата на смартфоне открывается нативный Telegram Web App:

- **Дизайн:** Dark Onyx & Emerald Neon с Glassmorphism и поддержкой тем Telegram.
- **5 интерактивных вкладок (Bottom Navigation Bar):**
  1. 🎓 **Курсы** — Каталог всех 8 программ, карточки с ценами, стеком технологий и всплывающим модальным окном с подробной программой по модулям.
  2. 🧩 **Квиз** — Интерактивный тест профориентации из 3 вопросов с мгновенным подбором профессии.
  3. 💰 **Калькулятор** — Расчет помесячной оплаты, скидки 15% и банковской рассрочки на 6/12 месяцев.
  4. 🤖 **ИИ Чат** — Встроенный RAG-консультант с быстрыми вопросами и подсказками.
  5. 🏢 **Кампус** — Информация о 24/7 коворкинге, оснащении (iMac, Core i7 32GB, 1 Гбит/с), филиалах в Ташкенте и быстрый звонок.
- **Интеграция Telegram WebApp SDK:**
  - Автоопределение имени пользователя (`Telegram.WebApp.initDataUnsafe.user`).
  - Тактильный виброотклик (`Telegram.WebApp.HapticFeedback`).
  - Отправка заявок напрямую боту (`Telegram.WebApp.sendData`) и на бэкенд (`/api/enroll`).

## ⚡ Быстрый старт

### 1. Запуск сайта, бота и Mini App одновременно
```bash
npm start
# или
npm run dev
```
Команда запускает:
1. Локальный веб-сервер на `http://localhost:8080` (и `http://localhost:8080/webapp`).
2. Telegram-бота `@ragm_bot`.
3. Безопасный публичный HTTPS-туннель для Telegram Mini App с автообновлением Menu Button в Telegram!

### 2. Запуск только Telegram-бота отдельно
```bash
npm run bot
```

### 2. 🎁 Сбор заявок на бесплатный пробный урок (Lead Capture FSM)
- Пошаговый сценарий: Имя ➔ Телефон (с поддержкой кнопки «📱 Отправить мой контакт») ➔ Выбор курса.
- Все заявки сохраняются в `leads.json`.
- Администраторы бота мгновенно получают карточку заявки с контактами и ссылкой на профиль студента.

---

### 3. 🧩 Тест профориентации (3-Step Quiz)
Интерактивный тест из 3 вопросов прямо в Telegram для тех, кто не знает с чего начать:
1. Выбор интересов (визуал, логика, архитектура, тестирование, нейросети).
2. Опыт в IT (с нуля, пробовал уроки, технический бэкграунд).
3. Главная цель (оффер Junior+, стартап, удаленка).
Бот выдает персональную рекомендацию курса с кнопкой быстрой записи на вводный мастер-класс.

---

### 4. 💰 Интерактивный калькулятор рассрочки
- Расчет стоимости по любому курсу:
  - Помесячная оплата без процентов.
  - Единовременная оплата с экономией **15%**.
  - Банковская рассрочка на 6 и 12 месяцев через Anorbank, Uzum Nasiya, Payme без первого взноса.

---

### 5. 🤖 Интеллектуальный RAG ИИ-Консультант
Пользователь может задать любой свободный вопрос на русском или узбекском языке:
- *«Сколько стоит курс Frontend?»*
- *«Нужен ли свой ноутбук для занятий?»*
- *«Где находится кампус в Ташкенте?»*
- *«Как проходит рассрочка?»*
- *«Выдается ли официальный диплом?»*

Бот находит ответ в базе знаний (`knowledge/courses.md`, `knowledge/center_info.md`, `knowledge/faq.md`) и формулирует ответ со всеми нюансами и контактами.

---

### 6. 🌐 Сквозная интеграция с веб-сайтом
- Когда посетитель оставляет заявку в форме на сайте `http://localhost:8080`, форма вызывает `POST /api/enroll`.
- Сервер `server.js` сохраняет заявку в `leads.json` и сразу отправляет оповещение ботом `@ragm_bot` администраторам в Telegram!
- В шапке и подвале сайта размещены прямые ссылки на бота: `@ragm_bot`.
